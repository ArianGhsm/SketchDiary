# SketchDiary

ربات تلگرامی دانشجویی با معماری **Inline-First** برای مدیریت احراز هویت، فرم‌های ثبت‌نام، نمره‌ها، خروجی‌گیری و زمان‌بندی اعلان‌ها.

---

## ✨ قابلیت‌های اصلی

### 👨‍🎓 دانشجو

- احراز هویت دانشجویی با شماره دانشجویی و معرفی کوتاه
- دریافت تایید یا رد خودکار بعد از بررسی نماینده
- مشاهده پروفایل تاییدشده
- مشاهده نمره‌ها و تحلیل عملکرد
- ورود به فرم‌ها از طریق لینک اینلاین
- تکمیل فرم‌های چندسوالی
- جلوگیری از ثبت تکراری

### 🎓 نماینده کلاس

- مشاهده و بررسی درخواست‌های احراز هویت
- ثبت گروهی نمره‌ها
- ارسال اطلاعیه همگانی
- ساخت فرم با:
  - عنوان
  - توضیح
  - مهلت اختیاری
  - ظرفیت اختیاری
  - waitlist
  - سوال‌های چندنوعی
- مدیریت فرم‌ها:
  - مشاهده جزئیات
  - بستن/بازگشایی
  - کپی ساختار فرم
  - جستجوی پاسخ‌ها
  - افزودن دستی دانشجو
  - حذف ثبت دانشجو
  - یادآوری به ثبت‌نکرده‌ها
- خروجی گرفتن به شکل:
  - لیست متنی نام‌ها
  - لیست متنی نام و شماره دانشجویی
  - `CSV`
  - `XLSX`
  - `JSON`
- زمان‌بندی انتشار فرم در کانال با `APScheduler`
- پشتیبانی از تکرار:
  - یک‌بار
  - هفتگی
  - ماهانه

### 🛠 مدیر

- پنل مدیریت
- غیرفعال‌کردن ثبت فعال دانشجو
- دسترسی به بررسی درخواست‌ها در صورت قرار داشتن در `ADMIN_IDS`

---

## 🧩 انواع سوال فرم

در نسخه فعلی این نوع سوال‌ها پشتیبانی می‌شوند:

- متن کوتاه
- متن بلند
- عدد
- تک‌گزینه‌ای
- چندگزینه‌ای
- منوی کشویی
- تاریخ/زمان

---

## 🔐 احراز هویت

جریان احراز هویت فعلی:

1. دانشجو از منوی اصلی روی `شروع احراز هویت` می‌زند.
2. شماره دانشجویی را می‌فرستد.
3. معرفی کوتاه ارسال می‌کند.
4. ربات درخواست را برای نماینده‌ها و مدیرهای مجاز می‌فرستد.
5. یکی از بررسی‌کننده‌ها درخواست را تایید یا رد می‌کند.
6. نتیجه به‌صورت خودکار به دانشجو برمی‌گردد.

ویژگی‌ها:

- تایید یک نفر کافی است.
- شماره دانشجویی تکراری روی حساب دیگر جلوگیری می‌شود.
- قبل از تایید، دسترسی کامل داده نمی‌شود.

---

## 🗂 فرم‌ها و ثبت‌نام

هر فرم می‌تواند این مشخصات را داشته باشد:

- `title`
- `description`
- `deadline_at`
- `capacity`
- `waitlist_enabled`
- `share_token`
- مجموعه‌ای از سوال‌ها

قوانین ثبت‌نام:

- فقط کاربر تاییدشده می‌تواند فرم را پر کند.
- برای هر کاربر در هر فرم فقط یک ثبت مجاز است.
- ترتیب ثبت ذخیره می‌شود.
- در صورت پر بودن ظرفیت:
  - اگر waitlist فعال باشد، پاسخ در لیست انتظار می‌رود.
  - اگر غیرفعال باشد، ثبت انجام نمی‌شود.

---

## ⏰ زمان‌بندی اعلان فرم

نماینده می‌تواند برای یک فرم، انتشار خودکار در کانال ثبت کند.

در زمان اجرا:

- از فرم الگو یک نسخه جدید ساخته می‌شود
- فرم جدید در وضعیت باز قرار می‌گیرد
- در کانال مشخص‌شده پیام انتشار ارسال می‌شود
- دکمه‌ی `ثبت‌نام در فرم` در همان پیام قرار می‌گیرد

برای scheduleهای تکرارشونده:

- بعد از هر اجرا، زمان بعدی هم ثبت می‌شود

## 🕒 استاندارد تاریخ و زمان

همه‌ی تاریخ‌های کاربرمحور باید:

- جلالی باشند
- بر اساس `Asia/Tehran` نمایش داده شوند
- برای زمان‌های مهم از `<tg-time ...>` استفاده کنند

نمایش مستقیم زمان خام UTC یا ISO در UI پروژه مجاز نیست.

## ⚙️ راه‌اندازی

### 1. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 2. تنظیمات

مقادیر مهم در `config.py`:

- `bot_token`
- `ADMIN_IDS`
- `MAIN_REP_STUDENT_NUMBER`
- `MAIN_REP_TELEGRAM_ID`
- `DB_PATH`
- `DEFAULT_STUDENTS_CSV`

### 3. seed اولیه

اگر جدول دانشجوها خالی باشد، ربات در شروع از فایل زیر seed انجام می‌دهد:

```text
data/default_students.csv
```

برای import دستی:

```bash
python import_students.py --replace-all
```

نکته:

- در startup، migration سبک برای دیتابیس‌های قدیمی هم انجام می‌شود تا ستون‌های جدید مثل `username` و `approved_at` به schema قبلی اضافه شوند.

### 4. اجرای ربات

```bash
python main.py
```

## 🔐 قوانین UX پروژه

- ناوبری command-centric ممنوع است.
- قابلیت جدید باید از دکمه اینلاین شروع شود.
- ورودی متنی فقط برای مرحله‌های data-entry مجاز است.
- همه‌ی flowها باید `لغو` یا `بازگشت` داشته باشند.
- قبل از تایید هویت، قابلیت کامل به کاربر داده نمی‌شود.
- شناسه‌ها و داده‌های قابل‌کپی با monospace نمایش داده می‌شوند.

## 🧰 رفع اشکال سریع

### دانشجو پیدا نمی‌شود

- فایل `data/default_students.csv` را بررسی کن.
- این دستور را اجرا کن:

```bash
python import_students.py --replace-all
```

### نماینده شناسایی نمی‌شود

- `MAIN_REP_TELEGRAM_ID` و `MAIN_REP_STUDENT_NUMBER` را چک کن.
- مطمئن شو همان کاربر واقعا احراز هویت شده است.

### schedule اجرا نمی‌شود

- شناسه کانال را بررسی کن
- مطمئن شو ربات در کانال permission ارسال پیام دارد
- زمان ارسال را با قالب معتبر ثبت کرده باشی
