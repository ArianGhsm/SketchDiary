# دستیار دانشجویان دندان‌پزشکی ورودی ۱۴۰۲

ربات تلگرام برای مدیریت خدمات آموزشی کلاس:
- ثبت هویت دانشجو
- نمایش نمرات و تحلیل عملکرد
- پنل نماینده کلاس برای مدیریت نمرات و اطلاعیه‌ها
- فرم/لیست‌سازی داخل تلگرام با لینک عضویت

## اصل طراحی

این پروژه **Inline-First** است:
- ناوبری کاربر با دکمه‌های اینلاین انجام می‌شود.
- ورودی متنی فقط برای ورود داده (مثل شماره دانشجویی، عنوان لیست، متن اطلاعیه) است.
- `/start` و `/cancel` فقط مسیر بازیابی هستند.

قراردادها:
- معماری: `ARCHITECTURE_FA.md`
- قرارداد UX اینلاین: `INLINE_UX_POLICY_FA.md`
- قانون مشارکت و آپدیت README: `CONTRIBUTING_FA.md`
- دستور ویژه ادیتورهای رباتی: `AGENTS.md`

## امکانات فعلی

- ثبت‌نام دانشجو با شماره دانشجویی
- پروفایل دانشجو
- نمایش نمرات
- تحلیل نمرات:
  - میانگین شخصی
  - رتبه در کلاس
  - میانگین کلاس
  - اختلاف با میانگین کلاس
- پنل نماینده کلاس:
  - ثبت گروهی نمره یک درس
  - ارسال اطلاعیه همگانی
  - ساخت فرم/لیست تلگرامی + لینک عضویت + مشاهده لحظه‌ای اعضا

## ساختار پروژه

- `main.py`: لایه ربات (UI، Conversation، Callbackها)
- `db.py`: لایه دیتابیس SQLite
- `grade_analytics.py`: محاسبات نمره و رتبه
- `text_utils.py`: تبدیل اعداد فارسی/انگلیسی و نرمال‌سازی
- `app_callbacks.py`: شناسه‌های callback اینلاین
- `assistant_profile.py`: هویت محصول و ماژول‌ها
- `import_students.py`: ایمپورت اطلاعات دانشجو از CSV
- `config.py`: تنظیمات توکن و نقش‌ها
- `data/`: پوشه مرکزی داده‌های مهم (برای بکاپ و جابجایی ساده)

## پیش‌نیازها

- Python 3.10+
- پکیج‌ها:
  - `python-telegram-bot`

## راه‌اندازی و اجرای بات

1. نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

2. تنظیمات در `config.py`:
- `bot_token`: توکن ربات
- `ADMIN_IDS`: آیدی عددی ادمین‌ها
- `MAIN_REP_STUDENT_NUMBER`: شماره دانشجویی نماینده اصلی
- `MAIN_REP_TELEGRAM_ID`: آیدی عددی تلگرام نماینده اصلی
- `DATA_DIR`: پوشه داده‌ها
- `DB_PATH`: مسیر دیتابیس SQLite داخل `data/`
- `DEFAULT_STUDENTS_CSV`: مسیر دیتای پیش‌فرض داخل `data/`

3. ایمپورت اولیه دانشجوها از CSV پیش‌فرض:

```bash
python import_students.py --replace-all
```

یا اگر فایل اختصاصی خودت را داری:

```bash
python import_students.py path/to/students.csv --replace-all
```

4. اجرای ربات:

```bash
python main.py
```

## فرمت CSV و ایمپورت

- ستون‌های لازم:
  - `StudentID`
  - یکی از این دو حالت:
    - `Name`
    - یا `FirstName` + `LastName`
- ستون `Password` نادیده گرفته می‌شود.
- سایر ستون‌ها به‌عنوان فیلد نمره ذخیره می‌شوند.
- ردیف ناقص حذف می‌شود.
- در `StudentID` تکراری، آخرین ردیف اعمال می‌شود.

## پنل نماینده کلاس

نماینده اصلی (پیش‌فرض):
- `Student Number`: `۴۰۲۱۱۲۷۲۰۰۳`
- `Telegram Numeric ID`: `۶۲۳۰۴۵۶۷۴۸`

دسترسی پنل نماینده فقط زمانی فعال می‌شود که:
1. آیدی تلگرام کاربر با آیدی نماینده یکی باشد.
2. همان کاربر با شماره دانشجویی نماینده در ربات ثبت شده باشد.

### ثبت گروهی نمره

فرمت لیست نمرات (هر خط):

```text
شماره‌دانشجویی، نمره
```

مثال:

```text
۴۰۲۱۱۲۷۲۰۰۳، ۱۸٫۵
۴۰۲۱۱۲۷۲۰۴۲، ۱۷
```

### فرم/لیست تلگرامی

جریان کار:
1. نماینده لیست جدید می‌سازد.
2. ربات لینک عضویت می‌سازد (`/start join_form_<id>`).
3. دانشجو لینک را می‌زند.
4. ربات تایید می‌گیرد.
5. بعد از تایید، دانشجو با نام و شماره دانشجویی ثبت‌شده وارد لیست می‌شود.
6. نماینده با دکمه `🔄 بروزرسانی لحظه‌ای` لیست اعضا را فوری آپدیت می‌کند.

## نگهداری و توسعه

**قانون اجباری:** هر تغییر در رفتار، UI، منوها، نقش‌ها، دیتابیس یا جریان‌ها باید همزمان در README آپدیت شود.  
تغییر کد بدون تغییر مستندات ناقص محسوب می‌شود.

**قانون اجباری Dependency:** اگر import جدید یا وابستگی جدید اضافه شد، `requirements.txt` باید در همان تغییر به‌روزرسانی شود.

چک خودکار pre-commit این دو قانون را بررسی می‌کند:
- `README.md` باید همراه تغییر کد آپدیت شود.
- `requirements.txt` باید با importهای پایتون همگام باشد.
