# مستندات پوشه `bot`

این پوشه هسته‌ی منطقی و UI ربات را نگه می‌دارد.

## فایل‌ها و نقش‌ها

### `application.py`

نقطه‌ی اتصال handlerها، stateها و callback routeها.

### `handlers.py`

جریان‌های اصلی پروژه:

- احراز هویت دانشجو
- بررسی درخواست توسط نماینده
- نمایش پروفایل
- نمایش نمره‌ها
- پنل نماینده
- ساخت فرم
- عضویت در فرم
- ارسال اطلاعیه

### `states.py`

فقط stateهای مرحله‌های data-entry در این فایل قرار می‌گیرند.

### `ui/keyboards.py`

تمام کیبوردهای اینلاین پروژه باید در این فایل تعریف شوند.

### `ui/texts.py`

متن‌های کاربرمحور در این فایل متمرکز شده‌اند تا لحن، چیدمان و قالب‌بندی در کل پروژه یکدست بماند.

### `services/`

ماژول‌های کمکی:

- `datetime_fa.py`: زمان جلالی و تهران
- `formatting.py`: helperهای monospace و HTML-safe
- `localization.py`: تبدیل سبک اعداد
- `parsers.py`: پارس ورودی‌های متنی
- `policies.py`: نقش‌ها، دسترسی‌ها و شناسه‌های مجاز

## قواعد توسعه در این پوشه

- منطق نمایش و متن را در `handlers.py` پخش نکنید.
- helper جدید را تا جای ممکن در `services/` قرار دهید.
- اگر متنی برای کاربر تغییر می‌کند، اول `ui/texts.py` را اصلاح کنید.
- اگر دکمه‌ای اضافه می‌شود، آن را در `ui/keyboards.py` مرکزی نگه دارید.
