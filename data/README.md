# پوشه `data`

این پوشه تنها محل مجاز برای داده‌های عملیاتی پروژه است.

## محتوا

- `students.db`
  - دیتابیس SQLite اصلی پروژه
  - شامل ثبت دانشجوها، درخواست‌های احراز هویت، نمره‌ها و فرم‌ها
- `default_students.csv`
  - داده‌ی اولیه برای seed جدول دانشجوها

## قوانین

- فایل دیتابیس را در مسیرهای پراکنده ایجاد نکنید.
- هر داده‌ی جدیدی که ماهیت عملیاتی دارد باید زیر همین پوشه بماند.
- برای بکاپ‌گیری، همین پوشه را کامل نگه دارید.

## کاربرد عملی

اگر محیط جدیدی بالا می‌آورید:

- با نگه‌داشتن `default_students.csv` می‌توانید seed اولیه داشته باشید.
- با نگه‌داشتن `students.db` می‌توانید وضعیت عملیاتی قبلی را منتقل کنید.
